# 🏦 ApexTrust Bank ATM System

A beginner-friendly **Python ATM simulation** that recreates the experience of using a modern Nigerian bank ATM.

The project was developed to practice Python programming concepts while demonstrating how an Automated Teller Machine (ATM) works.

---

## Features

### Authentication

- Username Login
- 4-digit PIN Verification
- Three Login Attempts
- Automatic Account Lock

### Banking Services

- Balance Enquiry
- Cash Deposit
- Cash Withdrawal
- Fund Transfer
- Airtime Purchase
- Bill Payment

### Account Services

- Mini Statement
- Transaction History
- Print Transaction Receipt
- Change PIN
- View Account Information

### Security

- Input Validation
- Daily Withdrawal Limit
- Balance Verification
- Secure Login Process

### Notifications

- SMS Alert Simulation
- Transaction Recording
- Date and Time Tracking
