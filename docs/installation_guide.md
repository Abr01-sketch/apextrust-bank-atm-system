# Installation Guide

Follow these steps to run the ApexTrust Bank ATM System on your computer.

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/apextrust-bank-atm-system.git
```

## 2. Navigate into the Project Folder

```bash
cd apextrust-bank-atm-system
```

## 3. Run the Program

```bash
python atm_system.py
```

or

```bash
python3 atm_system.py
```

No external libraries are required because the project uses only Python's built-in modules.
