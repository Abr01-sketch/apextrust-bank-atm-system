# Usage Guide

1. Launch the application.

2. Enter your username and 4-digit PIN.

3. Upon successful login, choose an option from the ATM menu.

Available services include:

- Balance Enquiry
- Cash Deposit
- Cash Withdrawal
- Transfer Funds
- Buy Airtime
- Pay Bills
- Mini Statement
- Change PIN
- View Transaction History
- Print Receipt
- Account Information
- Exit

After every successful transaction, the system asks whether you would like to perform another transaction.

Select **Yes** to return to the menu or **No** to exit the application.
